# Diagnóstico de Maturidade em Marketing — Turn Agência

Landing page interativa (quiz de 12 perguntas) que calcula o nível de maturidade de marketing de uma empresa e exibe o resultado em um gráfico radar, com CTA para WhatsApp.

Projeto single-file: todo o HTML, CSS e JavaScript estão em [`index.html`](index.html); imagens/ícones estão embutidos como base64 e as fontes (Poppins/Inter) são carregadas via Google Fonts CDN. Não há dependências externas de build.

## Publicação

Servido via GitHub Pages a partir da branch `main`, raiz do repositório.
